# Dashboard-Workload-by-Suyato

Single-file HTML dashboards, served via GitHub Pages. No build step — open the
`.html` files directly or via `index.html`.

- **`Marketing Workload — CEO Dashboard.html`** (linked from `index.html`) — marketing
  team workload/task tracker, backed by Supabase. See `ONBOARDING.md` for details.
- **`NSA Active Member Runway D0-D90.html`** — NSA new-store Active Member runway
  tracker (D0→D90 pace vs. 4,000-member target, cohort retention, activity impact,
  Wed-vs-Fri open-day comparison). Currently runs on simulated data per branch; the
  "นิยาม & Data Schema" tab documents the 4-sheet schema needed to wire in real data.
